# English Trainer

Плагин Obsidian для английских слов: автоматический перевод, словари, режим чтения книг и заучивание с интервальным повторением. Работает на компьютере и на iPhone.

## Что умеет

- **Добавить слово** (иконка 🌐 на ленте или команда «Добавить слово»): введите слово или фразу. Плагин сам найдёт перевод, транскрипцию, часть речи и примеры, покажет их (перевод можно поправить) и сохранит карточку в `English/Словарь/`. Оглавление — `English/Словарь.md`. Повторно слово не добавляется: откроется существующая карточка.
- **Загрузить книгу** (команда «Загрузить книгу (EPUB/PDF)»):
  - EPUB раскладывается на главы в `English/Книги/<Название>/Главы/`;
  - PDF открывается встроенным просмотрщиком;
  - у каждой книги свой словарь: `Словарь/` и `Словарь книги.md`.
- **Слово из книги:** выделите слово в главе или в PDF и выполните «Добавить выделенное в словарь книги» (в главе это есть и в меню по долгому нажатию или правому клику). В карточке будет предложение из книги и ссылка на это место: на абзац главы или на страницу PDF.
- **Заучивание** (иконка 🎓 или команда «Заучивание»):
  - выберите словарь и нажмите «Начать»;
  - сессия 10–20 слов, форматы от простого к сложному: карточка «знаю / не знаю», выбор из 4 вариантов в обе стороны, напечатать слово, пропуск в предложении;
  - прогресс (статус и дата следующего повторения) хранится в свойствах карточки.

## Источники перевода

Бесплатные, без ключей: русский Викисловарь, MyMemory, Free Dictionary API, Tatoeba. Нужен интернет. Без сети перевод можно вписать вручную.

## На iPhone

1. Дождитесь синхронизации хранилища (Obsidian Git).
2. Настройки → Сторонние плагины → перезагрузить список → включить English Trainer.
3. Удобно вынести команды на мобильную панель: Настройки → Мобильная версия → панель инструментов → добавить «Добавить слово», «Заучивание», «Добавить выделенное в словарь книги».

## Разработка

```bash
npm install
npm test               # модульные тесты
LIVE=1 npx vitest run tests/live.test.ts   # проверка источников через сеть
npm run deploy         # сборка и копирование в /Applications/Obsidian/.obsidian/plugins/english-trainer
```
