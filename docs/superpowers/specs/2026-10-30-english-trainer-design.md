# English Trainer — плагин Obsidian для изучения английских слов

Дата: 2026-10-30 · Статус: согласовано в чате («всё так, делай»)

## Зачем

Пользователь встречает незнакомое английское слово (чаще всего на iPhone) и хочет его записать. Сейчас это три ручных шага: напечатать слово, перевести в переводчике, оформить заметку. Плагин сводит это к одному действию: ввёл (или выделил) слово, а перевод, примеры, оформление и словарь появляются сами. Потом слова нужно заучивать прямо в Obsidian.

Успех — пользователь на телефоне за 5 секунд добавляет слово и в свободные 10 минут проходит сессию повторения.

## Цели

1. **Быстрое добавление слова.** Команда или кнопка открывает окно ввода. Плагин сам получает:
   - перевод (несколько значений);
   - транскрипцию;
   - часть речи;
   - 2–3 примера в предложениях с переводом.

   Затем создаёт карточку-заметку в общем словаре. Если слово уже есть, дубль не создаётся, а открывается существующая карточка.
2. **Словари.**
   - **Общий словарь:** папка карточек и заметка-оглавление, где слова отсортированы по дате добавления (новые сверху).
   - **У каждой книги свой отдельный словарь** с такой же структурой.
3. **Режим книги.**
   - Пользователь загружает файл EPUB или PDF.
   - **EPUB:** плагин раскладывает книгу на заметки по главам.
   - **PDF:** файл открывается встроенным просмотрщиком Obsidian.
   - При чтении пользователь выделяет слово и выбирает «Добавить в словарь книги». Карточка попадает в словарь этой книги и содержит предложение из книги и ссылку на место в тексте:
     - EPUB — на абзац (block id);
     - PDF — на страницу.
4. **Режим заучивания** — отдельный экран, сессия из 10–20 слов, удобная одной рукой на iPhone.
   - **Форматы идут вперемешку, от простого к сложному:**
     1. карточка: показать перевод, затем «знаю / не знаю»;
     2. выбор из 4 вариантов (EN→RU и RU→EN);
     3. напечатать слово по переводу;
     4. пропуск в предложении из примера.
   - **Интервальное повторение** (как в Anki): новые и ошибочные слова приходят чаще, выученные — реже.
   - **Источник слов перед сессией:** общий словарь, словарь конкретной книги или всё сразу.
   - **В карточке хранятся** статус (новое / учу / выучено) и дата следующего повторения.
   - **В конце сессии** — итог: сколько правильно и какие слова стоит повторить.
5. **Полная работа на iPhone (Obsidian mobile).**

## Не цели

- Свой EPUB-ридер с пагинацией и вёрсткой. Читаем главы как обычные заметки Obsidian.
- Перевод целых предложений или страниц.
- Озвучка в квизах. Ссылка на аудио в карточке — только если источник её даёт.
- Перенос старых записей из `English/03_Vocabulary`: пользователь сказал, что там всё плохо оформлено. Оформление делаем с нуля.
- Публикация в каталоге плагинов Obsidian.

## Анти-цели (провал, даже если «работает»)

- Добавление слова требует больше одного осмысленного действия или подвисает без обратной связи.
- На iPhone что-то не работает или неудобно: мелкие кнопки, клавиатура перекрывает поле.
- Плагин портит заметки пользователя (главы книги, словари) или плодит дубли.
- Нужен платный ключ или регистрация.

## Ограничения

- Obsidian 1.9.12, десктоп (macOS) и мобильная версия. `isDesktopOnly: false`, никаких Node/Electron API, никакого `fs`.
- Сеть только через `requestUrl` из API Obsidian: на мобильных он работает без CORS.
- Хранилище `/Applications/Obsidian` синхронизируется через Obsidian Git (папка `.obsidian/plugins` уходит на телефон) и Syncthing. PDF исключены из git, поэтому PDF-книги на телефон через git не попадут — это ограничение пользователя, не плагина.
- Без внешних сервисов с ключами.

## Решения пользователя

- Источник сессии выбирается перед стартом: общий словарь, книга или всё.
- Нужны все четыре формата квизов вместе.
- Форматы книг: EPUB и PDF.
- Словарь книги отделён от общего.
- Старую папку словаря не использовать как образец.

## Решения, принятые мной (пользователь может оспорить)

1. **Где живёт код.** Исходники в `~/Projects/obsidian-english-trainer` (git, TypeScript, esbuild). Сборка копируется в `/Applications/Obsidian/.obsidian/plugins/english-trainer/`.
2. **Источники перевода, всё бесплатно и без ключей; при ошибке источник пропускается, результат собирается из того, что ответило:**
   1. Русский Викисловарь (`ru.wiktionary.org`, разбор wikitext англоязычной статьи): значения, транскрипция, синонимы, примеры с переводом.
   2. MyMemory (`api.mymemory.translated.net`): запасной перевод, если в Викисловаре слова нет.
   3. Free Dictionary API (`api.dictionaryapi.dev`): транскрипция, часть речи, английские определения и примеры, ссылка на аудио.
   4. Tatoeba (`api.tatoeba.org`): предложения с переводом на русский.

   Перед сохранением пользователь видит результат в окне и может поправить перевод.
3. **Карточка слова** — заметка `<слово>.md`:
   - **Свойства (frontmatter):**
     - `type: word`, `word`, `translation`, `transcription`, `pos`;
     - `dictionary` (`general` или имя книги), `source_link` (для книги);
     - `status`, `due`, `interval`, `ease`, `reps`, `lapses`;
     - `added`, `tags: [english/word]`.
   - **Тело заметки:** заголовок, значения, примеры, синонимы, а для книжного слова — цитата из книги со ссылкой.
4. **Структура папок (настраивается):**
   - `English/Словарь/` — карточки общего словаря;
   - `English/Словарь.md` — оглавление;
   - `English/Книги/<Название>/` — `<Название>.md` (оглавление книги со ссылками на главы и словарь), `Главы/`, `Словарь/`, `Словарь книги.md`, исходный файл.
5. **Конвертация EPUB.** JSZip читает архив, DOMParser — OPF/XHTML. Главы идут по spine; HTML переводится в Markdown функцией `htmlToMarkdown` из API Obsidian. Картинки пока не переносятся.
6. **Ссылка на место в книге.**
   - **EPUB:** плагин дописывает в конец абзаца block id `^w-<короткий id>` (если его там ещё нет) и ставит ссылку `[[Глава#^w-…]]`.
   - **PDF:** выделение берётся из `window.getSelection()`, номер страницы — из DOM просмотрщика. Ссылка `[[книга.pdf#page=N]]`, цитата — выделенный фрагмент и его окружение, если оно доступно.
7. **Интервальное повторение.** Упрощённый SM-2:
   - оценки «не знаю / знаю» (в карточке ещё «трудно»), в тестах верный ответ = «знаю»;
   - статус «новое», если `reps = 0`; «выучено», если интервал не меньше 21 дня; иначе «учу».
8. **Сессия.**
   - Берутся слова, у которых подошёл срок; если их меньше нормы, добавляются новые (до 10 новых за сессию).
   - Размер сессии по умолчанию 15.
   - Формат выбирается по стадии слова: новое — карточка и выбор, учу — выбор, ввод, пропуск, выучено — ввод и пропуск.
   - Неверно отвеченные слова возвращаются в конец сессии ещё раз.
9. **Вход в функции.**
   - Иконки на ленте: «добавить слово», «заучивание».
   - Команды для всех действий, включая «Добавить выделенное в словарь книги».
   - Пункт в контекстном меню редактора. На iPhone эти команды можно вынести на мобильную панель инструментов.
10. **Оглавления** перестраиваются автоматически при добавлении или удалении карточки. Это обычный markdown-список ссылок, поэтому Dataview не нужен.
11. **Тесты.** Vitest для чистой логики: SM-2, разбор ответов источников, генерация markdown, разбор EPUB на фикстуре, выбор слов в сессию. UI проверяется вручную в Obsidian.

## Что остаётся строителю

Вёрстка экранов (CSS), тексты интерфейса, разбор редких шаблонов Викисловаря, обработка ошибок сети и пустых ответов.
